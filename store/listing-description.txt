Ace for GitHub is Ace in your browser. It opens on github.com's own addresses and files every pull request, issue and check by what needs you, so you stop working out whose turn it is on every visit.

WHAT YOU GET
• Working set: every pull request you are in, across repositories, in four groups: Needs You, Waiting, Running, Settled
• One pull request, one screen: failing checks, unresolved threads and the commits pushed since you last looked, beside the diff
• Go to any definition: hold Command over a name in a diff or a file, click a use to go to where it is written, or click where it is written to see everything that uses it
• Every move has a key: next file, previous file, mark it seen, older and newer commit, and one key to reach any file or name
• Checks that say why: a failed run opens on the test that failed, with each warning and where it came from
• Issues, Actions, commits, releases and notifications in the same grouping

Every review, comment and merge goes back through GitHub, so a colleague who has never installed it sees your work as usual.

PRIVACY
No separate login. Ace uses the GitHub session you already have, and your code and reviews stay in your browser. No analytics and no remote code.

Ace is the app for you and your agents: https://useace.dev
