GitAce Extension privacy policy

Last updated: 16 August 2026

GitAce Extension improves GitHub pull request, issue and Actions pages. It comes as an extension for Chrome, Firefox and Safari. This policy covers each of them. There is no GitAce Extension account and no GitAce Extension server.

What we process

The extension reads GitHub pages and API responses in your signed-in browser session so it can draw its review screens. That content stays in your browser.

The extension stores display settings and a local cache of GitHub payloads in your browser's extension storage, on your device, so pages open quickly.

What we do not do

  • We do not sell user data.
  • We do not use your GitHub content for advertising.
  • We do not use your data for credit or lending decisions.

Error reporting

There is none. GitAce Extension has no error reporting service and no third-party endpoint of any kind. When something fails that GitAce Extension carries on through, it writes a line to your own browser's console, where only you can see it. Nothing about a failure leaves your machine.
